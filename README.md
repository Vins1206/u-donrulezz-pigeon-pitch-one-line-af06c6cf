## What it does

`main.py` (Python standard library only) writes exactly one line of plain
text, at most 200 characters, to `/output/entry.txt`: the elevator pitch
a city pigeon gives to investors for its startup.

> I'm raising a seed round - actual seeds - to franchise my good-luck poop: for $19.99, my flock precision-bombs tourists, and getting crapped on is the premium tier.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The output is a single line, 164 characters, plain UTF-8 text.
